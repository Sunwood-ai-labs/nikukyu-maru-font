# 生成見本との比較結果

2026-09-13 / 現行0.100 / 判定: デザイン再現は未達。

「フォントとして描画できる」と「採用画像の魅力を再現している」は別です。前の完成報告は前者の検証に偏っていました。現在の書体は太い猫装飾付き書体として動作しますが、生成見本にある風船のような丸みや肉球を十分に再現していません。

## 方法と証拠

比較元は `references/01-nikukyu.png`（1254×1254）。CSSで元画像の該当領域を表示し、右側に同じ文字列をWOFF2で実描画しました。元画像の再生成・輪郭修正は行っていません。Chromeの読込完了を確認後、実画面を3枚撮影しています。

- `compare-1.png`: ねこのいる / 暮らし
- `compare-2.png`: にゃんこ / ネコとおひるね
- `compare-3.png`: CAT & nap / 0123456789

左右は縦横比を保ち、高さを基準に調整（横幅上限あり）。元画像に残る透明余白と文字ごとの高さの違いがあるため、厳密な輪郭重ね合わせではありません。字間と骨格を目視評価するための比較です。ピクセル一致率や再現率の数値は算出していません。比較範囲は見本の主要6行で、他の収録文字には生成見本がなく、忠実度を判定できません。

## 共通して大きく違う点

1. 見本の端は半円状に膨らみます。現行は平らな切り口に小さな角丸を付けた形が多く、特に「い・ら・し・T・数字」で硬さが残ります。
2. 見本の猫耳は低く幅広い2つの山で、字の本体につながっています。現行は細く尖った突起です。「ね・ん・お・A」は耳同士も近く、毛先のように見えます。
3. 見本の文字内側の穴は小さく丸い形が中心です。現行は元書体の大きい穴、角のある穴、しずく状の穴が残り、黒い部分の量と印象が違います。
4. 見本の行は、文字ごとに形と間を詰めた一体感があります。現行は全角セルのかなと比例幅の英字を組み合わせており、特に「にゃんこ」の「ん–こ」周辺が離れて見えます。画像の1行をそのまま等幅フォントにするだけでは再現できません。

## 見本に寄せる修正の順序

1. 「暮・こ・い・ら・し」を、見本に沿った輪郭へ個別に描き直す。一律の太字化・角丸半径だけでは骨格差が残ります。
2. 猫耳を幅広く低い形にし、文字ごとに接続位置を調整する。
3. 「こ・し」の粒を可視化し、「る・a・8」の肉球抜きを作る。「る」は生成画像内で通常穴と肉球穴が使い分けられているため、標準字形＋装飾異体字などの設計が必要です。
4. 英数字の端、穴、4・7の骨格、文字間を個別調整する。
5. 同じ比較ページで再撮影し、その後に濁点・半濁点と小サイズ可読性を再確認する。

このターンは比較・評価の依頼に合わせ、フォント本体を変更していません。前の「動作検証済み」は維持できますが、「生成見本を再現した完成版」という判定はできません。
